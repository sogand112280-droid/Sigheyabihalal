راهنمای نصب سایت در GitHub Pages

۱) ZIP را استخراج کنید.
۲) فایل‌ها و پوشه‌های داخل ZIP را مستقیماً در ریشه مخزن GitHub خود آپلود کنید؛ خود پوشه را داخل مخزن نگذارید.
۳) مطمئن شوید index.html کنار style.css و پوشه assets در ریشه مخزن است.
۴) در Settings > Pages شاخه main و پوشه /(root) را انتخاب کنید.
۵) چند دقیقه صبر کنید و سایت را باز کنید.

اگر آدرس GitHub شما متفاوت است، آدرس‌های robots.txt و sitemap.xml را اصلاح کنید. تصاویر این بسته تصویرسازی گرافیکی هستند، نه عکس واقعی افراد. بخش «رضایت مشتریان» شامل راهنمای عمومی است و ادعای نقل‌قول واقعی ندارد. متن سایت مجوز یا وابستگی رسمی دولتی را تأیید نمی‌کند.
